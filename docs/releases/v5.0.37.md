# BoxPlayer v5.0.37

这次更新围绕媒体库浏览与首页管理：分类和收藏项可以更灵活地放到首页，媒体服务器的列表、播放列表和加载状态也得到改进。

## 媒体库与首页

- 统一分类、系列和播放列表的首页放置菜单，支持自定义显示名称、移除和重命名收藏卡片。
- 优化首页栏目加载和卡片渲染，改善大媒体库滚动时的响应速度。
- 调整详情页标题、类型与评分布局，完善海报菜单、收藏和播放进度操作。
- 改进封面、广播网络和元数据补全，补充媒体来源评分展示。

## 媒体服务器

- 改进 Emby、Jellyfin 和 Plex 的目录分页与首页内容隔离，减少不同分类间的内容串扰。
- 补充媒体服务器播放列表操作和服务器连接测速入口。
- 初次打开空列表时在内容区中央显示加载图标；加载后续页面时在列表底部显示小图标。
- 优化服务器海报、详情和继续观看信息。

## 同步与兼容性

- 改进 Trakt 请求和登录状态处理。
- 修正夸克 Cookie 解析的兼容性问题。
